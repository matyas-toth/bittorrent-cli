# Contributing

Thanks for helping improve `bittorrent-cli`.

1. Use Node.js 22.12 or newer and run `npm install`.
2. Create a focused branch and add tests for behavior changes.
3. Run `npm run validate` before opening a pull request.
4. Keep engine code independent from Ink so it remains testable and usable by headless commands.

Please use only legal torrents and never commit copyrighted fixtures. Tiny synthetic torrents or
freely licensed public-domain samples are welcome.
